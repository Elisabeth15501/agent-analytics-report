关于这个项目

这是一个 vibe coding 作品集项目：从采集层（collect_usage_data.py）到报告层（generate_report.py / analyze_tokens.py），覆盖工作区 traces、workbuddy.db、usage-log.json 等多源数据，支持 Markdown / HTML / JSON 输出，并内置 GLM 系列模型的人民币计价库。

页面顶部的两个入口分别展示了 工具实际产出的示例报告（示例报告）与 CI 自动生成的 Allure 测试结果（Allure 测试结果），可直接点开查看。
